# School ERP — Student Management System

A centralized school management platform designed to help small schools digitize their daily administrative work.

## Problem Statement
Small schools often manage student records, attendance, examinations, and fee collection manually or using separate tools. This system aims to simplify these operations in one platform.

## Key Features
- Student registration and record management
- Attendance management
- Class and subject management
- Examination and marks management
- Fee management
- Role-based dashboards for school staff

## Technology Stack
- **Frontend:** Flutter and Dart
- **Backend:** Java and Spring Boot
- **Database:** MySQL

## System Architecture
Flutter frontend communicates with the Spring Boot backend, which handles application logic and database operations using MySQL.
